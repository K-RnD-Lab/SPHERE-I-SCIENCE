# Misfolding primer

## Domino model

1. One **PrPSc** contacts **PrPC** on the surface of a neuron.
2. PrPC adopts the same misfolded β-sheet-rich state.
3. Rate accelerates as PrPSc concentration rises (autocatalysis).
4. Insoluble plaques / fibrils → spongiform pathology.

## Not the same as

| | Prion domino | Alzheimer's Aβ |
|--|--------------|----------------|
| Protein | PrP | Amyloid-β, tau |
| Transmissible between humans via tissue | Yes (rare) | No (debated propagation) |
| S5/S4 lane | S5-A, S4-A | Future S5-B/C if expanded |

## «Fuel»

**Fuel** = remaining pool of **PrPC** available to be converted. Lowering PrP (siRNA/ASO) = removing fuel from the fire, not extinguishing existing PrPSc.
